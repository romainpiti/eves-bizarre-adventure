# Eve’s bizarre adventures ♡ — version 44

This build adds the final reunion ending and gift interaction:
- Eevee says “SURPRISE!”, followed by the final thank-you dialogue.
- The bouquet and envelope sprites are included with their white backgrounds removed.
- Clicking the envelope opens the letter; the small × button, clicking outside, or Escape closes it.
- A discreet “Restart a new story” button in the top-left returns to the welcome screen and resets the story.

Open `index.html` in a browser. The site uses local assets from the `assets/` folder.

- The welcome screen uses the new blue, starry sky background.
- The website title is now “Eve’s bizarre adventures”.
- Eevee appears above the final gifts after the dialogue ends; she can be dragged and clicked to show “I’m so glad to know you!”.
